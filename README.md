# 🎉 パーティツール

パーティや飲み会で使える、ブラウザだけで動くユーティリティ集です。
ビルド不要・外部ライブラリなし・スマホ優先のデザインです。

## ツール一覧

| ツール | 内容 |
| --- | --- |
| 🎯 ルーレット | メンバーから1人を抽選。「当たった人を次から外す」で連続抽選も可能 |
| 🤝 チーム分け | 「チーム数」または「1チームの人数」でランダムに分ける |
| 🔢 順番決め | 発表順・席順などをランダムに並べる |
| 🎲 サイコロ・コイン | 4〜100面ダイスを最大10個、コイントス、履歴つき |
| ⏱️ タイマー | プリセット・微調整つきカウントダウン。残り3秒で音、終了時はアラームとバイブ |
| 🏆 スコアボード | ±1/5/10/100 の加減点、タップで直接入力、順位で並べ替え、トップに👑 |
| 🅱️ ビンゴ | 1〜75の抽選マシン。日本語で番号を読み上げ、1つ戻す機能つき |
| 💴 割り勘 | 端数単位（1〜1000円）、切り上げ/切り捨ての比較、傾斜（多めに払う人）に対応 |

## 部屋で遊ぶ（複数のスマホで共有）

ホーム画面で「新しい部屋を作る」と6桁の部屋番号とQRコードが表示されます。参加者は番号を入力するか、QRコード（招待リンク）から入室します。別のグループは別の部屋番号を使うので、同時に何組でも遊べます。

| ツール | 主催者（部屋を作った人） | 参加者 |
| --- | --- | --- |
| 🅱️ ビンゴ | 番号を引く。リーチ・ビンゴの人が一覧に出る。景品ルーレットを回す | 自分専用のカードの出た番号をタップすると、紙のカードのように穴があく。そろった列は金色に光る。リーチ・ビンゴは穴から自動判定 |
| 🏆 スコアボード | 得点を操作 | 見るだけ（リアルタイム更新） |
| 🎯 ルーレット | 回す | 同じルーレットが同時に回り、同じ人に止まる |
| 🤝 チーム分け / 🔢 順番決め | 決める | 結果が表示される |
| ⏱️ タイマー | スタート・一時停止 | 全員の画面で同時にカウントダウン・同時に終了 |

- **景品ルーレット**: 主催者がテキストファイル（.txt / .csv、Excel の Shift_JIS の CSV も可）または貼り付けで景品を登録すると、ビンゴになった人のスマホに「🎁 景品ルーレットを回す」ボタンが出て、本人が回します（主催者も「代わりに回す」で回せます）。全員の画面で同じルーレットが回り、個数が多い景品ほど当たりやすくなります（抽選はサーバー側）。ファイルは1行に1つ `商品名,個数`（個数を省くと1個、1行目の見出しは無視）。ルーレットにのせる景品は主催者が選べます: **すべてのせる**（残っている景品すべて）／**上から順に**（一覧の上から N 種類だけを同じ確率でのせ、個数が0になった景品の代わりに次の景品を補充。N は 1〜20、初期値 5）
- **ビンゴの通知**: 誰かがビンゴになると、部屋の全員の画面に「🎉 ○○ さんがビンゴ！」を大きく表示し、効果音とバイブで知らせます（ビンゴ以外の画面を開いていても表示）
- 操作できるのは主催者だけです（主催者の端末に保存された鍵で判定。ビンゴになった本人の景品ルーレットと、カードの印つけを除く）
- 主催者が共有ツールを開くと、参加者の画面も自動で同じツールに切り替わります
- 部屋に入っている間は画面が消えないようにします
- 最後の操作から24時間たち、誰も接続していない部屋は自動で削除されます
- サイコロ・割り勘などは部屋に関係なく各自の端末で使えます

## 共通の機能

- **共有メンバー**: 一度登録した参加者を全ツールで使い回せます（カンマ・改行区切りでまとめて貼り付け可）
- **自動保存**: メンバー・スコア・ビンゴの進行状況・各種設定はブラウザ（localStorage）に保存されます
- **公平な乱数**: `crypto.getRandomValues` を使い、偏りのない抽選をします
- **サウンド切替**: 右上の 🔊 で効果音をオン/オフ
- **画面スリープ防止**: タイマー作動中は画面が消えないようにします（対応ブラウザのみ）
- ダーク/ライトモードは端末の設定に自動で合わせます
- **PWA対応**: ホーム画面に追加してアプリのように使え、一度開けばオフラインでも動きます

## 公開URL

Cloudflare Workers で公開しています（`main` ブランチへのプッシュで自動デプロイ）。

## 開発

部屋の機能を含めて動かすには Node.js が必要です。

```bash
npm install
```

```bash
npm run dev
```

その後 <http://localhost:8787> を開きます（Cloudflare と同じ仕組みがローカルで動きます。アカウントは不要です）。

部屋を使わないツールだけなら、`public/index.html` をブラウザで直接開いても動きます。

## デプロイ（Cloudflare Workers）

Cloudflare の管理画面で「Workers & Pages」→「作成」→「リポジトリをインポート」からこのリポジトリを選ぶと、`main` へのプッシュごとに `npx wrangler deploy` が実行されます。Worker 名は `party-tools`（`wrangler.jsonc` の `name`）にしてください。

| 設定（Worker の「設定」→「ビルド」） | 値 |
| --- | --- |
| 本番ブランチ（ブランチの管理） | `main` |
| ビルドコマンド | 空欄 |
| デプロイコマンド | `npx wrangler deploy` |

本番ブランチが `main` 以外になっていると、`main` にプッシュしても公開されません。

### 自動ビルドが始まらないとき

GitHub からの通知が Cloudflare に届かないと、プッシュしてもビルドが始まりません。その場合は、ダッシュボードの「設定」→「ビルド」で Git リポジトリを接続し直すか、Workers Builds API で手動ビルドを開始します（**ユーザー**の API トークンが必要。アカウントのトークンは使えません）。

1. `GET /accounts/{account_id}/builds/workers/{script_tag}/triggers` で `trigger_uuid` を調べる（`script_tag` は `GET /accounts/{account_id}/workers/scripts` の `tag`）
2. `POST /accounts/{account_id}/builds/triggers/{trigger_uuid}/builds` に `{"branch":"main"}` を送る

この環境のネットワークでは `wrangler deploy` の静的ファイルのアップロードが失敗するため、手元からの直接デプロイではなく上の方法を使います。

部屋の状態は Durable Objects（SQLite）に保存されます。無料プランで利用できます。

> PWA の機能（ホーム画面への追加・オフライン）は HTTPS か `localhost` で開いたときだけ有効です。`index.html` を直接開いた場合は通常のWebページとして動きます。

## ディレクトリ構成

```
wrangler.jsonc               Cloudflare の設定
src/worker.js                サーバー（部屋の作成・WebSocket・状態管理）
design/                      ビンゴカードのデザイン案（Higgsfield で生成。配信はしない）
public/                      ブラウザに配信するファイル
  index.html                 エントリーポイント
  manifest.webmanifest       PWA の設定（アプリ名・アイコンなど）
  sw.js                      Service Worker（オフライン対応）
  _headers                   レスポンスヘッダー設定
  icons/                     アプリアイコン
  css/style.css              スタイル
  js/core.js                 共通処理（ルーティング、保存、メンバー、UI部品、乱数、サウンド）
  js/room.js                 部屋への接続・ホーム画面の部屋カード
  js/vendor/qrcode.js        QRコード生成（qrcode-generator, MIT License）
  js/tools/*.js              各ツール（1ファイル = 1ツール）
```

## ツールの追加方法

1. `public/js/tools/mytool.js` を作成し、`Party.register()` で登録します。

   ```js
   'use strict';

   Party.register({
     id: 'mytool',          // URL は #/mytool
     name: 'マイツール',
     icon: '✨',
     desc: 'ホームに表示する説明',
     render(root) {
       const { h } = Party;
       root.append(h('p', null, 'こんにちは'));
       // タイマー等を使う場合は後片付け関数を返す
       return () => {};
     },
   });
   ```

2. `public/index.html` に `<script src="js/tools/mytool.js" defer></script>` を追加します（読み込み順がホームでの並び順になります）。
3. `public/sw.js` の `APP_FILES` にファイルを追加し、`VERSION` を上げます（オフラインで使えるようにするため）。

部屋で共有するツールにする場合は `room: true` を付け、`Party.room`（`active` / `isHost` / `room` / `send()` / `on()`）を使います。サーバー側の処理は `src/worker.js` の `apply()` に追加します。

`Party` には `h`（DOM生成）、`store`（保存）、`members`（共有メンバー）、`memberEditor`、`stepper`、`segmented`、`field`、`randInt`、`shuffle`、`beep`、`fanfare`、`vibrate`、`copy`、`toast`、`keepAwake` などの共通部品があります。
