# 🎉 パーティツール

パーティや飲み会で使える、ブラウザだけで動くユーティリティ集です。
ビルド不要・外部ライブラリなし・スマホ優先のデザインです。

## ツール一覧

| ツール | 内容 |
| --- | --- |
| 🎯 ルーレット | メンバーから1人を抽選。「当たった人を次から外す」で連続抽選も可能 |
| 🤝 チーム分け | 「チーム数」または「1チームの人数」でランダムに分ける |
| 🔢 順番決め | 発表順・席順などをランダムに並べる |
| 🎲 サイコロ・コイン | 4〜100面ダイスを最大10個、コイントス、履歴つき |
| ⏱️ タイマー | プリセット・微調整つきカウントダウン。残り3秒で音、終了時はアラームとバイブ |
| 🏆 スコアボード | ±1/5/10/100 の加減点、タップで直接入力、順位で並べ替え、トップに👑 |
| 🅱️ ビンゴ | 1〜75の抽選マシン。日本語で番号を読み上げ、1つ戻す機能つき |
| 💴 割り勘 | 端数単位（1〜1000円）、切り上げ/切り捨ての比較、傾斜（多めに払う人）に対応 |

## 共通の機能

- **共有メンバー**: 一度登録した参加者を全ツールで使い回せます（カンマ・改行区切りでまとめて貼り付け可）
- **自動保存**: メンバー・スコア・ビンゴの進行状況・各種設定はブラウザ（localStorage）に保存されます
- **公平な乱数**: `crypto.getRandomValues` を使い、偏りのない抽選をします
- **サウンド切替**: 右上の 🔊 で効果音をオン/オフ
- **画面スリープ防止**: タイマー作動中は画面が消えないようにします（対応ブラウザのみ）
- ダーク/ライトモードは端末の設定に自動で合わせます

## 使い方

`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで動かす場合:

```bash
python3 -m http.server 8000
```

その後 <http://localhost:8000> を開きます。

GitHub Pages などの静的ホスティングにそのまま置いて公開することもできます。

## ディレクトリ構成

```
index.html          エントリーポイント
css/style.css       スタイル
js/core.js          共通処理（ルーティング、保存、メンバー、UI部品、乱数、サウンド）
js/tools/*.js       各ツール（1ファイル = 1ツール）
```

## ツールの追加方法

1. `js/tools/mytool.js` を作成し、`Party.register()` で登録します。

   ```js
   'use strict';

   Party.register({
     id: 'mytool',          // URL は #/mytool
     name: 'マイツール',
     icon: '✨',
     desc: 'ホームに表示する説明',
     render(root) {
       const { h } = Party;
       root.append(h('p', null, 'こんにちは'));
       // タイマー等を使う場合は後片付け関数を返す
       return () => {};
     },
   });
   ```

2. `index.html` に `<script src="js/tools/mytool.js" defer></script>` を追加します（読み込み順がホームでの並び順になります）。

`Party` には `h`（DOM生成）、`store`（保存）、`members`（共有メンバー）、`memberEditor`、`stepper`、`segmented`、`field`、`randInt`、`shuffle`、`beep`、`fanfare`、`vibrate`、`copy`、`toast`、`keepAwake` などの共通部品があります。
